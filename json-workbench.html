Notes

Everything runs in your browser. No network calls, no uploads — works offline from file:// and from a static host alike. The document is kept in localStorage so a reload does not lose work.

The schema validator covers the common draft 2020-12 keywords: types, required, properties, patternProperties, additionalProperties, propertyNames, items, prefixItems, contains, enum, const, allOf/anyOf/oneOf/not, if/then/else, $ref and $defs, numeric and string bounds, and common format values. Load several schema files together and cross-file $ref resolves by $id.
